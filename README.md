# Greenhill Food Co-op Ordering System

A small Flask web application for the Greenhill Food Co-op weekly grocery round.

## Features
- Member login by member number
- View products in the current open round
- Place an order
- Unit and weight based pricing
- View personal orders and totals
- Coordinator view of all orders and totals by product

## Prerequisites
- Python 3.10+
- Git

## Setup
1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run the app

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
